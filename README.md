# Toolora — Everything You Need, One Place

Toolora adalah platform kumpulan utilitas digital online modern yang menyediakan puluhan alat praktis untuk kebutuhan sehari-hari, pelajar, kreator konten, pebisnis, dan developer dalam satu tempat tanpa instalasi aplikasi dan tanpa registrasi akun.

---

## 🌟 Keunggulan Utama

- **100% Pemrosesan Lokal di Browser:** Semua kompresi gambar, formatting JSON, perhitungan matematis, dan operasi kriptografi dijalankan langsung di browser menggunakan Web Crypto API dan Canvas API. Tidak ada data yang diunggah ke server eksternal.
- **Tanpa Database Eksternal & Tanpa Akun:** Akses instan ke seluruh alat secara gratis tanpa registrasi, tanpa login, dan tanpa batasan.
- **Dukungan Dark Mode & Light Mode:** Desain modern, bersih, minimalis SaaS dengan auto-detect preferensi sistem dan toggle tema manual.
- **Pencarian Cerdas Instan (Command Palette):** Cari alat secara cepat dengan sinonim Bahasa Indonesia dan navigasi keyboard (tekan `/` atau tombol Cari).
- **Favorit & Riwayat Lokal:** Tandai alat favorit Anda dan pantau riwayat penggunaan yang tersimpan aman di `LocalStorage` peramban.
- **Cadangkan & Pulihkan (Backup & Restore):** Ekspor dan impor preferensi serta daftar favorit Anda kapan saja dalam format file JSON.
- **Siap Deploy ke Vercel:** Konfigurasi SPA rewrite telah disediakan di `vercel.json`.

## 💻 Panduan Instalasi & Menjalankan Lokal

### Prasyarat
- Node.js versi 18 atau lebih tinggi
- npm atau pnpm atau yarn

### Langkah-langkah:
1. Clone repositori ini:
   ```bash
   git clone https://github.com/username/toolora.git
   cd toolora
   ```

2. Instal dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```

4. Buka peramban di alamat:
   ```
   http://localhost:3000
   ```

## 🚀 Panduan Deployment ke Vercel

Toolora adalah aplikasi React Single Page Application (SPA) yang 100% berbasis klien, sehingga proses deployment ke Vercel sangat mudah:

### Melalui Vercel CLI:
```bash
npm install -g vercel
vercel
```

### Melalui Vercel Dashboard (GitHub):
1. Push kode ke repositori GitHub Anda:
   ```bash
   git init
   git add .
   git commit -m "feat: initial Toolora release"
   git branch -M main
   git remote add origin https://github.com/username/toolora.git
   git push -u origin main
   ```
2. Buka [vercel.com](https://vercel.com) dan klik **"Add New Project"**.
3. Hubungkan repositori GitHub Anda.
4. Pengaturan default otomatis terdeteksi:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Klik **"Deploy"**. File `vercel.json` sudah tersedia di repositori untuk memastikan navigasi rute internal (seperti `/tools/calculator`) tetap berfungsi normal setelah halaman di-refresh.
